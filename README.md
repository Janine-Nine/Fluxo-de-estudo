# 📚 StudyFlow — Organizador de Estudos

**Organize o que você deseja aprender, passo a passo.**

O **StudyFlow** é uma aplicação desenvolvida para ajudar iniciantes em tecnologia a organizar seus estudos, definir objetivos, acompanhar prazos e visualizar o progresso de aprendizagem de forma simples e intuitiva.

A proposta é transformar metas de estudo em objetivos organizados, incentivando a consistência, o planejamento e a evolução contínua.

---

## ✨ Funcionalidades

- 🎯 **Gerenciamento de objetivos:** crie e organize suas metas de aprendizagem.
- 📊 **Progresso geral:** acompanhe visualmente sua evolução nos estudos.
- ⏳ **Controle de status:** identifique objetivos não iniciados, em andamento e concluídos.
- 📅 **Organização por prazo:** acompanhe as datas definidas para cada objetivo.
- 🔍 **Filtros de status:** visualize os objetivos conforme sua situação.
- ↕️ **Ordenação personalizada:** organize os objetivos por prazo, data de criação ou ordem alfabética.
- ✏️ **Edição de objetivos:** atualize as informações das suas metas.
- 🗑️ **Exclusão de objetivos:** remova objetivos que não fazem mais parte do seu planejamento.
- 💾 **Armazenamento local:** os dados são salvos automaticamente no navegador por meio do LocalStorage.

## 💾 Persistência de dados

O StudyFlow utiliza o **LocalStorage do navegador** para salvar os objetivos automaticamente.

Isso permite que as informações permaneçam disponíveis após atualizar ou fechar a página, desde que os dados do navegador não sejam removidos e o acesso ocorra na mesma origem.

**Importante:** o armazenamento é local. Os dados não são sincronizados automaticamente entre dispositivos ou navegadores.

## 🚀 Como executar o projeto

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra a pasta no Visual Studio Code.
3. Localize o arquivo HTML principal.
4. Abra o arquivo no navegador ou utilize uma extensão de servidor local, como o Live Server, caso seja necessária.

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Substitua `URL_DO_SEU_REPOSITORIO` pelo endereço real do seu repositório no GitHub.

## 🎯 Objetivo do projeto

O StudyFlow tem como objetivo facilitar a organização pessoal dos estudos, ajudando estudantes iniciantes a desenvolver hábitos de planejamento, acompanhar metas e construir uma rotina de aprendizagem mais consistente.

O projeto também representa uma oportunidade de praticar conceitos de desenvolvimento de software, organização de interfaces e gerenciamento de dados no navegador.
